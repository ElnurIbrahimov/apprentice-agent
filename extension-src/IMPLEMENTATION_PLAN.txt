### Changes to ws.ts

#### A. Add Ping Constants (after line 12)

```
const PING_INTERVAL = 25_000;        // 25 seconds

```

#### B. Add Module-Level Ping State (after line 11)
```
let _pingTimer: ReturnType<typeof setInterval> | null = null;
let _lastMessageTime = 0;
```

#### C. Add Helper Functions (after clearWsTimers, line 17)
```typescript
function recordMessageTime() {
  _lastMessageTime = Date.now();
}

function startPingLoop(socket: WebSocket) {
  if (_pingTimer) return;
  _pingTimer = setInterval(() => {
    const now = Date.now();
    const { activeStream } = useStore.getState();
    if (socket.readyState === WebSocket.OPEN && 
        (now - _lastMessageTime) > PING_GRACE_PERIOD &&
        activeStream) {
      socket.send(JSON.stringify({ type: 'ping' }));
    }
  }, PING_INTERVAL);
}

function stopPingLoop() {
  if (_pingTimer) {
    clearInterval(_pingTimer);
    _pingTimer = null;
  }
}
```

#### D. Call startPingLoop in socket.onopen (line 81)
After useStore.getState().setWs(socket), add:
```

```

#### E. Call stopPingLoop in socket.onclose (line 98)

#### F. Record Message Time in socket.onmessage (line 153)
