# Aura Android 2026-07-09 bug sweep

The user reported "model selection not working, nothing is working properly, absolute mess, UI/UX is a mess." After deep code review + emulator reproduction, root causes:

## Primary cause: stale APK
- The user is running `aura-debug-v0.10.0.apk` shipped at 15:48
- 6 unpushed commits landed AFTER 15:48 (0391a30, d1b5423, b5e5967, 7865980, c9bf25d, 4d692a7)
- The most critical unpushed commit is 4d692a7 — "self-heal persisted DataStore values with the broken ':cloud' suffix" — which is THE fix for the model selection bug
- Live verification: `curl http://localhost:11434/v1/models` shows the real model IDs all have `:cloud` suffix; the v0.10.0 APK stored them WITHOUT that suffix, so every chat request 404s

## Secondary bugs found in code review
1. **SettingsViewModel.kt:25** — `defaultModel` default state is `"ollama:deepseek-v4-pro:cloud"` (with `:cloud`!). Reload() overwrites this, but pre-reload Settings render shows a wrong value. More importantly, this is the ID the picker returns — if the user picks from chips, the result is inconsistent with the picker display.
2. **SettingsScreen.kt:206-211** — Quick-pick chips use model IDs that don't exist in the live API:
   - `ollama:deepseek-v4-pro` → should be `ollama:deepseek-v4-pro:cloud`
   - `ollama:kimi-k2.7-code` → DOES NOT EXIST (real: `kimi-k2.6:cloud`)
   - `ollama:minimax-m2.7` → should be `ollama:minimax-m2.7:cloud`
   - `ollama:gemma4:31b` → should be `ollama:gemma4:31b-cloud`
   - `ollama:qwen3.5:397b` → DOES NOT EXIST
3. **MoaProvider.kt:47-48, MoaPresetRepository.kt:35-36, assets/moa_presets.json** — reference models `glm-5.2` and `kimi-k2.7-code` that don't exist (real: `glm-5.1:cloud` and `kimi-k2.6:cloud`). MoA fails on every run.
4. **GeminiProvider.kt:132-135** — hardcoded `["gemini-1.5-flash", "gemini-1.5-pro"]`. Gemini 1.5 is deprecated. Other providers (Anthropic, Ollama Cloud) fetch from `/v1/models` API. Gemini should too.
5. **NavGraph.kt:35-36** — duplicate `import androidx.compose.material3.Surface`.

## Fix plan
Atomic commits in order:
1. `fix(settings): use live model ids in default-model chips` — fix the 5 broken chip IDs in SettingsScreen
2. `fix(moa): use real reference model ids in default preset` — fix glm-5.2/kimi-k2.7-code to glm-5.1:cloud/kimi-k2.6:cloud (both code + json asset + tests if any)
3. `fix(gemini): fetch live model list instead of hardcoded 1.5 fallback` — add /v1/models API call, with hardcoded fallback only when API fails
4. `chore(nav): remove duplicate Surface import`
5. `fix(settings): use live :cloud-suffixed default model in SettingsViewModel state` — match the picker output
6. `chore: build + verify v0.10.1 debug APK with model fixes`
