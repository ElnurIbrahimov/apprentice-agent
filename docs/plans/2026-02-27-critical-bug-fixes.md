**Goal:** Fix 6 critical/high-severity bugs exposed by the cloud model migration audit.

**Architecture:** All fixes are surgical — no refactors. Each fix either (a) replaces a hardcoded local model name with `Config.get_model(role)`, (b) moves a logger definition to before it is used, or (c) rewrites a raw HTTP call to use `ollama.Client` with proper cloud routing.

## Task 5: Fix `mirrormind.py` — Raw HTTP to localhost for cloud models

**Files:**
- Modify: `aura/tools/mirrormind.py:1–20` (imports), `aura/tools/mirrormind.py:88–135` (`__init__` and `_call_llm`)

**Context:** MirrorMind uses `requests.post(f"{self.ollama_url}/api/generate", ...)` — the legacy local-only endpoint. Cloud models need `ollama.Client(host="https://ollama.com", headers={"Authorization": "Bearer <key>"})`.

**Step 1: Add ollama import**

`mirrormind.py` imports `requests` but not `ollama`. Add:
```python

import ollama
```
(add alongside existing imports at the top)

**Step 2: Add cloud host constant**

After the imports, add:
```python
_OLLAMA_CLOUD_HOST = "https://ollama.com"
```

**Step 3: Rewrite `__init__` to initialize both clients**

Replace the `__init__` body (everything from `self.ollama_url = ...` through `self.description = ...`):
```python
def __init__(
    self,
    ollama_url: str = "http://localhost:11434",
    model: str = None,
    quality_threshold: float = 0.75,
    max_iterations: int = 2
):
    self.ollama_url = ollama_url.rstrip("/")
    self.model = model or Config.MODEL_FAST
    self.quality_threshold = max(0.0, min(1.0, quality_threshold))
    self.max_iterations = max(1, min(5, max_iterations))
    self.name = "mirrormind"
    self.description = "Self-critique and response improvement system"

    # Initialize ollama clients (mirrors CognitiveTheater pattern)
    self._local_client = ollama.Client(host=ollama_url)
    self._cloud_client = None
    api_key = os.getenv("OLLAMA_API_KEY")
    if api_key:
        self._cloud_client = ollama.Client(
            host=_OLLAMA_CLOUD_HOST,
            headers={"Authorization": f"Bearer {api_key}"}
        )
        logger.info("[MirrorMind] Cloud client initialized")
```

**Step 4: Add `_get_client()` method** (insert after `__init__`, before `_call_llm`):
```python
def _get_client(self) -> ollama.Client:
    """Return cloud client for cloud models, local client otherwise."""
    if self.model.endswith("-cloud"):
        if self._cloud_client:
            return self._cloud_client
        logger.warning(f"[MirrorMind] Cloud model {self.model} requires OLLAMA_API_KEY — critique disabled")
        return None
    return self._local_client
```

**Step 5: Rewrite `_call_llm` to use ollama.Client**

Replace the existing `_call_llm` method body:
```python
def _call_llm(self, prompt: str, temperature: float = 0.7) -> str:
    """Call Ollama to generate a critique or improvement."""
    client = self._get_client()
    if client is None:
        return ""  # Cloud model requested but no API key — silent skip

    try:
        response = client.generate(
            model=self.model,
            prompt=prompt,
            options={"temperature": temperature}
        )
        return response.get("response", "").strip()
    except Exception as e:
        logger.error(f"[MirrorMind] LLM call failed: {e}")
        return ""
```

## Task 6: Fix `cognitive_theater.py` — Fallback sets cloud model on local client

**Files:**
- Modify: `aura/tools/cognitive_theater.py:127–134`

**Context:**
```python
def _get_client(self) -> ollama.Client:
    if self.model.endswith("-cloud"):
        if self._cloud_client:
            return self._cloud_client
        else:
            logger.warning(...)
            self.model = Config.MODEL_FAST  # BUG: MODEL_FAST is also cloud!
            return self._local_client       # Returns local client with cloud model name
    return self._local_client
```

When `OLLAMA_API_KEY` is not set, the fallback mutates `self.model` to `Config.MODEL_FAST` (which is `gemini-3-flash-preview:cloud`) and then returns `self._local_client`. The next call to `_get_client` hits the same branch again — the model is still cloud, cloud client still None. Infinite bad state.

**Step 1: Fix the fallback to return `None` instead of broken state**

Replace the `_get_client` method:
```python
def _get_client(self) -> Optional[ollama.Client]:
    """Return cloud client for cloud models, local client otherwise.

    Returns None if a cloud model is requested but OLLAMA_API_KEY is not set.
    """
    if self.model.endswith("-cloud"):
        if self._cloud_client:
            return self._cloud_client
        logger.warning(
            f"[CognitiveTheater] Cloud model '{self.model}' requires OLLAMA_API_KEY — deliberation skipped"
        )
        return None
    return self._local_client
```

**Step 2: Add `Optional` to the imports**

The file already imports from `typing`. Ensure `Optional` is in the import:
```python
from typing import Dict, Optional
```

**Step 3: Fix `_call_llm` to handle `None` client gracefully**

Read `_call_llm` (lines 137+) and wrap the client call:
